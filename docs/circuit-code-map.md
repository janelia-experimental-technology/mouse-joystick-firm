# Circuit-to-code map

Which part of the rig each piece of this firmware talks to, through which
board connector and schematic block, over which nets and GPIOs, and which
protocol verbs and events the host sees for it. Generated by
`tools/circuit_code_map.py` from the rig's component registry
([`atlas/components.yaml`](https://github.com/peterpolidoro/mouse-joysticks-mech/blob/main/atlas/components.yaml)) and the board's records
([`kicad/board-manifest.yaml`](https://github.com/peterpolidoro/mouse-joystick-pcb/blob/v1.0/kicad/board-manifest.yaml), [`kicad/board.yaml`](https://github.com/peterpolidoro/mouse-joystick-pcb/blob/v1.0/kicad/board.yaml));
do not edit, change those and run the script. GPIO numbers are the board's
as built at `v1.0` (`src/BoardPins.hpp` carries the same numbers with their history).

## By part

### Spur gear pair

Driving gear on the motor shaft, driven gear on the lever axis. The mirrored station has its own driven gear. The gear ratio is the number the firmware's angle scaling depends on.

### Reaction torque sensor

350 ohm bridge, 1.5 mV/V nominal (the firmware converts on the certificate mean, 1.5605 mV/V), 5 in-oz, at the rear of the lever axis. The board excites it, amplifies it, samples it at 1 kHz and puts a copy on the torque BNC. The left station reads a pull negative where the right reads positive.

| | |
| --- | --- |
| Board connector | `J2001` |
| Schematic block | `torque_bridge_0_3v3_ina821` in sheet `brake_torque_sensor` |
| Nets and GPIOs | `TQ_SPI_CIPO` GP12, `TQ_SPI_COPI` GP11, `TQ_SPI_SCK` GP10, `TQ_CAL_EN` GP18, `TQ_CONVST_CS` GP15 |
| Firmware | [`src/BrakeTorqueHw.hpp`](https://github.com/peterpolidoro/mouse-joystick-firm/blob/v1.0.0/src/BrakeTorqueHw.hpp), [`src/ADS8689Device.hpp`](https://github.com/peterpolidoro/mouse-joystick-firm/blob/v1.0.0/src/ADS8689Device.hpp), [`src/BoardCalibration.hpp`](https://github.com/peterpolidoro/mouse-joystick-firm/blob/v1.0.0/src/BoardCalibration.hpp) |
| Protocol | `TQ`, `STATUS (torque)`, `ev TOUCH`, `ev PULL / PUSH` |
